# Public-safe content
This repository is public.
- Use fictional apps, companies, people and data only (the course uses a fictional
  library app called ShelfShare).
- Never add email addresses, phone numbers, home-directory paths, internal links,
  customer or employer names, or anything credential-shaped.
- The only personal identifier allowed is the maintainer's public GitHub handle.
- Run `python3 verify.py --only privacy` after editing any file.
